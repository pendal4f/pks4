Практическое задание: Разработка "Интерактивной системы 
управления производством на ASP.NET Core MVC" 
ЦЕЛЬ: 
Разработка веб-приложения для автоматизации управления 
производственными процессами с функциями: 
 Планирования и контроля выполнения заказов; 
 Управления производственными линиями; 
 Учета материалов и продукции. 
ЗАДАНИЕ: 
1. ТРЕБОВАНИЯ К БАЗЕ ДАННЫХ (Entity Framework Core) 
1. Product (Продукт) 
 Id (int) - уникальный идентификатор продукта; 
 Name (string) - наименование продукта (обязательное поле); 
 Description (string) - текстовое описание продукта; 
 Specifications (string/JSON) - технические характеристики в формате 
JSON; 
 Category (string) - категория продукта; 
 MinimalStock (int) - минимальный необходимый запас на складе; 
 ProductionTimePerUnit (int) - время производства одной единицы (в 
минутах). 
2. ProductionLine (Производственная линия) 
 Id (int) - уникальный идентификатор линии; 
 Name (string) - название производственной линии; 
 Status (string) - текущий статус ("Active"/"Stopped"); 
 EfficiencyFactor (float) - коэффициент эффективности (0.5-2.0, где 1.0 - 
нормальная скорость); 
 CurrentWorkOrderId (int?) - ID текущего выполняемого заказа (может 
быть null). 
3. Material (Материал) 
 Id (int) - уникальный идентификатор материала; 
 Name (string) - наименование материала; 
 Quantity (decimal) - текущее количество на складе; 
 UnitOfMeasure (string) - единица измерения ("кг", "шт", "литр" и т.д.); 
 MinimalStock (decimal) - минимальный запас для пополнения. 
4. ProductMaterial (Связь продукта и материала) 
 ProductId (int) - ссылка на продукт (внешний ключ); 
 MaterialId (int) - ссылка на материал (внешний ключ); 
 QuantityNeeded (decimal) - необходимое количество материала для 
производства одной единицы продукта. 
5. WorkOrder (Производственный заказ) 
 Id (int) - уникальный идентификатор заказа; 
 ProductId (int) - ссылка на производимый продукт; 
 ProductionLineId (int?) - назначенная производственная линия (может 
быть null); 
 Quantity (int) - количество единиц к производству; 
 StartDate (DateTime) - плановая дата начала производства; 
 EstimatedEndDate (DateTime) - расчетная дата завершения; 
 Status (string) - статус выполнения ("Pending"/ "InProgress"/ "Completed"/ 
"Cancelled"). 
2. API СПЕЦИФИКАЦИЯ 
1. Материалы 
 GET /api/materials?low_stock=true Получить список материалов 
(только с низким запасом); 
 POST/api/materials {name, quantity, unit, min_stock} Добавить 
новый материал; 
 PUT /api/materials/{id}/stock {amount} Изменить количество на 
складе. 
2. Продукты 
 GET /api/products?category={id} Список продуктов (с фильтром по 
категории); 
 GET /api/products/{id}/materials Получить материалы для продукта; 
 POST/api/products {name, prod_time, category} Создать новый продукт. 
3. Производственные линии 
 GET /api/lines?available=true Список линий (только доступные); 
 PUT /api/lines/{id}/status {status} Изменить статус линии; 
 GET /api/lines/{id}/schedule - Получить расписание линии. 
4. Заказы 
 GET /api/orders?status=active&date=today Фильтрация заказов; 
 POST/api/orders{product_id, quantity, line_id} Создать заказ с 
авторасчетом; 
 PUT /api/orders/{id}/progress {percent} Обновить прогресс выполнения; 
 GET /api/orders/{id}/details Полная информация по заказу. 
5. Расчетные методы 
 POST/api/calculate/production {product_id, quantity} Рассчитать время 
производства; 
3. ТРЕБОВАНИЯ К ИНТЕРФЕЙСУ 
1. Панель материалов 
Функционал: 
Таблица материалов со столбцами: 
 Название; 
 Количество (с цветовой индикацией при низком запасе); 
 Единицы измерения. 
Простая форма добавления/редактирования: 
 Название; 
 Текущее количество; 
 Минимальный запас; 
Кнопка "Пополнить" для быстрого увеличения количества. 
2. Панель продуктов 
Функционал: 
Фильтр по категориям и поиск продукта. 
Таблица продуктов со столбцами: 
 Название; 
 Время производства (мин/шт); 
 Категория. 
Форма создания/редактирования: 
 Все основные данные; 
 Привязка необходимых материалов; 
 Установка времени производства. 
3. Панель заказов 
Функционал: 
Таблица заказов со столбцами: 
 Номер; 
 Продукт; 
 Количество; 
 Статус (цветовая маркировка); 
 Срок выполнения. 
Форма создания заказа: 
 Выбор продукта → автоматическое заполнение времени производства; 
 Ввод количества → авторасчет сроков; 
 Выбор линии из доступных. 
 
 
Кнопки: 
 "Запустить в производство"; 
 "Отменить заказ". 
4. Интерактивная панель линий 
Функционал: 
Визуальное отображение всех линий: 
 Статус (работает/остановлена); 
 Текущий продукт; 
 Прогресс выполнения. 
Управление: 
 Кнопка "Запустить линию" (выбор продукта); 
 Кнопка "Остановить"; 
 Регулировка коэффициента эффективности. 
 
 
Простое расписание: 
 Список назначенных заказов. 
Возможность переноса сроков выбором новой даты. 
 
 
Дополнительные требования: 
Расчет времени выполнения: 
 Время = (Количество × ВремяНаЕдиницу) / КоэффЭффективности 
Контроль материалов: 
 Автоматическая проверка при создании заказа.
