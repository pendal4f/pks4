# pks4 — Практические работы №4 и №5 (ASP.NET Core MVC + EF Core)

Репозиторий содержит два учебных проекта:

## Практическое №4 — pks4 (Путеводитель по городам)
**Задача:** MVC-приложение со справочником городов и достопримечательностей.

**Что реализовано:**
- Список городов и карточки с описанием/населением.
- Поиск в реальном времени + поиск по сокращениям/алиасам (например: мск, спб, регистр не важен).
- Страницы деталей города и достопримечательности.
- Тёмная/светлая тема (data-bs-theme) и аккуратные стили кнопок.
- Данные заполнены (seed) + расширенные описания (источник: Wikipedia).


## Практическое №5 — pks5 (Управление производством)
**Задача:** MVC-панели + REST API для управления материалами, продуктами, линиями и заказами.

**Что реализовано:**
- EF Core + SQLite, сущности: материалы, продукты, производственные линии, заказы, нормы расхода материалов на продукт.
- MVC-страницы:
    - Материалы (добавление/пополнение, проверка совпадения названия и единиц измерения с модальным окном).
    - Продукты (добавление, настройка норм расхода материалов).
    - Заказы (создание, запуск, отмена, прогресс в реальном времени через polling).
    - Линии (статус Active/Stopped, текущий заказ).
- Бизнес-логика:
    - Проверка достаточности материалов при создании заказа.
    - Списание материалов при создании заказа.
    - При отмене заказа возвращается неиспользованный остаток материалов пропорционально прогрессу.
    - Если линию остановили во время выполнения — активные заказы отменяются, остаток материалов возвращается.
- REST API /api/* (материалы/продукты/линии/заказы/расчёт времени).

Отдельно: примеры запросов для Postman (включая получение ошибок 400/404/405/415/500): pks5/README.md.
